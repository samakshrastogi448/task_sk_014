# Blue Hour Atlas — Project 014

A premium photo-led city-elopement experience built with React, Vite and GSAP.

## Direction
- **Category:** City Elopement / Editorial Story
- **Visual language:** blue-hour city grid, civil paperwork, rooftop frames, neon circles, contact-map photography and late-night editorial pacing
- **Scenes:** 12
- **Motion:** restrained GSAP reveals and image drift with reduced-motion fallback
- **Customization:** edit `src/data.js` for names, date, location, photos and story copy

## Commands
```bash
npm install
npm run dev
npm run build
npm run qa:production
```

Production QA targets `https://tasksk014.vercel.app` and validates mobile, tablet, laptop, desktop, accessibility, runtime stability, broken images, overflow and reduced-motion behavior.
